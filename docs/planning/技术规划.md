# 可折叠 3D 打印机技术规划

日期：2026-11-10

## 一、目标与边界

### 当前 HMW

> **我们如何在保留现有打印机线性运动学的情况下，让龙门／立柱及关联杆件快速折叠收纳，并在展开锁紧后重复恢复到可打印状态？**

### 第一版必须完成

> 实机测量 → 解除结构阻挡 → 折叠 → 收纳 → 展开到基准 → 锁紧 → 回零 → 同一 G-code 恢复打印。

### 明确不做

- 不把 AI、错因识别或后台应用带回项目；
- 不在第一版同时做五轴、旋转中打印或长尺寸打印；
- 不在手动折叠机构未成立前开发自动展开；
- 不宣称一套机构未经改造就适用于所有打印机；
- 不用自动调平代替龙门方正、机械锁紧和回零验证。

## 二、路线选择

### 主路线：铰链折叠＋机械基准＋两点锁紧

**改“走”与机器框架，保留打印时的线性运动学。**

机构分为四层：

1. **转动层**：铰链或转轴只负责折叠，不承担全部打印载荷；
2. **基准层**：展开后由固定平面、定位销或三点接触恢复位置；
3. **锁紧层**：两处螺钉、夹具或锁扣消除转动自由度并提高刚度；
4. **收纳层**：杆件、工具头、线缆、料卷和床板均有固定位置，不在运输中自由摆动。

选择理由：FoldaRap、Odin-5、Elka1 和 Positron 已提供可参考先例；与剪刀轴相比，不需要重写非线性运动学，能把时间集中在折叠机构和重复定位上。

### 备选路线：伸缩导轨＋铰链收纳

参考 Nomad 的伸缩 Y 导轨与铰链罩。只有在主路线受到明显碰撞或收纳尺寸限制时采用。展开后仍需机械锁紧，不能把伸缩滑轨当成定位基准。

### Dark horse／高风险比较：剪刀 Z 轴

保留 FoldaRapX、X printer 和 Foldup 作为机构与算法研究，但不作为第一版主路线。若选择它，必须同时接受非线性映射、可变力比、回差、同步、回零和固件开发任务。

## 三、系统分解

### 1. 结构线

- 实机底座、龙门／立柱、关联杆件与运动包络；
- 折叠转轴、展开基准、两点锁紧、运输固定；
- 床板、工具头、线缆、Bowden 管和料卷的收纳位置；
- 箱体或提手与框架的受力关系。

**关键输出**：打印状态图、折叠状态图、转动轨迹与碰撞区图、锁紧受力路径图。

### 2. 电控线

第一版尽量复用原机控制器、电机、限位与加热系统，只增加必要的状态检测：

- 展开到位开关；
- 锁紧状态开关或明确的机械确认；
- 运输／折叠状态下的运动禁止；
- 后续自动展开才增加驱动电机、减速和独立控制。

**接口原则**：未展开、未锁紧时，不允许进入正常打印状态；加热与运动安全不因折叠结构而降低。

### 3. 算法线

首版不重写 Cartesian／CoreXY 运动学，算法集中在机器状态与恢复流程：

```text
STOWED（已收纳）
→ DEPLOYING（展开中）
→ MECHANICALLY_LOCKED（机械锁定）
→ HOMING（回零）
→ CALIBRATION_CHECK（校准检查）
→ READY（允许打印）
```

需要保存或记录：

- 展开／锁紧状态；
- 回零结果与 Z 偏移；
- 折叠前后基准测量；
- 同一测试 G-code 的三次执行结果。

只有在机械结构改变工具头与电机的线性关系时，才进入 Klipper 自定义运动学；五轴则另走 Open5x／Fractal 的逆运动学与切片路线。

## 四、工作包与验收

| 工作包 | 具体任务 | 可验证输出 |
|---|---|---|
| WP1 实机与场景 | 确定 A1、A1 mini 或课程实机；测量杆件、龙门、床、线缆与附件 | 带尺寸照片、测量表、首要阻挡说明 |
| WP2 折叠机构 | 转轴、基准、两点锁紧、折叠轨迹与避让 | 可反复动作的 1:1 机构样机 |
| WP3 收纳系统 | 杆件、工具头、床板、管线、料卷与提手／箱体 | 收纳状态实物与尺寸记录 |
| WP4 电控与状态 | 到位、锁紧、回零和运动禁止 | 状态表、接线图、联锁演示 |
| WP5 校准与打印 | 重复展开、回零、测高、同一文件三次打印 | 原始数据、失败记录和对比照片 |

## 五、验证指标

当前没有实机基线，以下是需要采集的指标，不是已经达成的性能：

- 展开与折叠后的长、宽、高及体积；
- 从拿出设备到可以打印的时间；
- 所需工具数量与锁紧操作数量；
- 连续 20 次折叠／展开中的卡滞、碰撞、松脱次数；
- 每次展开后的龙门方正、基准位置与 Z 回零差异；
- 是否需要重新调平，以及调平耗时；
- 同一 G-code 三次打印的成功率与尺寸差异；
- 搬运后线缆、加热件、床板和工具头是否松脱。

**冻结规则**：先测未改装机器的基线，再确定折叠版的允许误差；不能用厂商标称精度替代本机基线。

## 七、风险与停止条件

| 风险 | 处理 |
|---|---|
| 找不到实机或尺寸来源 | 停止虚构尺寸，先取得实机／官方 CAD／可靠测量 |
| 折叠后龙门刚度不足 | 增加独立基准与锁紧，不让铰链单独承重 |
| 每次展开都要重新调平 | 先改机械基准；不能把 ABL 当根治 |
| 杆件和管线碰撞 | 先修改折叠轨迹或独立收纳，不强行加电机 |
| 手动机构仍不可靠 | 不进入自动展开 |
| 剪刀轴需要非线性固件 | 从第一版剥离，转作高风险研究 |
| 与现有项目差异只剩外观 | 回到锁紧、收纳、展开时间或重复定位中的具体可测差异 |

## 八、课程原型的最小演示

> 普通打印一件小测试件 → 折叠并收纳 → 搬运到另一张桌子 → 展开并锁紧 → 回零 → 用同一 G-code 再打印。

演示必须同时展示机器机构与打印结果。若只能证明“可以装进箱子”，而不能证明“展开后恢复打印”，就还没有完成本方向的核心验证。

## 九、当前假设

- 上游快照只作参考，具体零件必须经过本机尺寸与许可证核查。
