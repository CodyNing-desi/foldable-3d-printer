# 可折叠 3D 打印机：现有准备工作总结

日期：2026-11-12

## 一、当前任务状态

**方向已经确定：做可折叠 3D 打印机，折叠本身是需要完成的工程任务。**本课程不再把商业场景可行性当作前置闸门；后续重点是机构、图纸、原型、控制、校准和真实打印验证。

当前主线为：

> **以一台具体机器为对象，采用铰链折叠＋独立机械基准＋两点锁紧，展开后保留原线性运动学，并验证折叠后能否恢复打印。**

五轴、旋转中打印、长打印和自动展开均不进入第一版的必做范围。

### 5. 算法基础与技术路线已核对

`docs/research/算法基础与技术路线.md` 已整理：

## 五、当前结论

已有准备已经足以支撑**开始画自己的机构图、测量实机和制作关键折叠样机**。后续不再需要围绕“要不要折叠”反复论证，也不应继续无边界收集资料；工作重心应转到具体零件、图纸、动作和验证数据。
