# 折叠方案虚拟端可行性验证准备

日期：2026-11-12

## 一、验证能回答什么

虚拟端用于排除明显不可行的几何、运动与受力关系，并比较机构路线。它可以回答：

- 折叠过程中是否碰撞；
- 所需空间是否真的能缩小；
- 连杆是否有解、是否经过死点；
- 根部／关节的载荷与变形是否值得继续做样机；
- 展开后能否回到同一机械基准。

**虚拟模型不能单独证明长期可靠性、实际打印精度、材料耐久或折叠机构的寿命。**这些仍需实机测试。

## 二、统一输入与坐标

- 长度统一为 mm，质量为 kg，力为 N，力矩为 N·mm，角度内部计算统一为 rad；
- 固定同一个底座坐标系、喷嘴参考点、床面基准和转轴定义；
- 模型必须包含床板、工具头、料盘、线缆、电源和需要拆卸的附件；
- 每次计算记录上游 CAD／实测来源、机构版本、参数表版本和运行代码 commit；
- 未测量参数保持“待测量”，不得用外观估计值冒充实测。

## 三、各路线需要建立的模型

| 路线 | 最小虚拟模型 | 主要输出 | 一票否决的几何／运动问题 |
|---|---|---|---|
| F01／F03 根部翻折 | 立柱／龙门作为刚体绕根部转轴旋转；床、底座、喷头为障碍 | 扫掠包络、最小间隙、折叠外包络、根部力矩 | 无法完成折叠、穿过床／底座、展开后基准不重合 |
| F02 横臂收拢 | 横臂与工具头绕 Z 滑块接口转动 | 横臂末端轨迹、线缆避让、接口附加质量与力矩 | 横臂与立柱／床碰撞，或新增接口使打印区不可用 |
| F04／F10 避让折叠 | 参数化四连杆或槽轨从动件；分段检查位置与姿态 | 连杆位置、可达性、死点、驱动位移、碰撞 | 某些角度无装配解、运动中断、需穿过障碍物 |
| F05／F12 伸缩立柱 | 多级套筒截面、重叠长度、导向与锁紧位置 | 总高、重叠率、侧向间隙、有效 Z 行程 | 导轨不连续、重叠不足、锁定后仍失稳或行程不足 |
| F06／F14 外部翻转 | 整机与托架绕外支点转动；重心随姿态变化 | 操作力矩、柜体深度、支撑载荷、失电保持需求 | 支点力矩过大、柜体无法容纳、支撑未承力 |
| F11 箱体联动 | 箱盖、连杆／拉索、机架和附件的联合运动 | 开盖角与机架角关系、附件包络、重心与容纳 | 箱盖无法带动到位、附件干涉、闭合尺寸不成立 |
| F13 抽屉 Y 模组 | 完整 Y 模组沿独立滑轨移动；工作位有定位与多点锁紧 | 抽拉空间、停靠重复性、线缆弯曲、工作区偏移 | 抽拉与立柱折叠互相阻挡、工作位基准不确定 |
| 剪刀轴 dark horse | 理想剪刀几何＋实际偏置与驱动输入 | 非线性映射、几何增益、低位驱动需求 | 出现奇异、不可达或超出电机／机构允许范围 |

## 四、验证顺序

### 阶段 A：几何与状态

1. 读入实测／CAD 参数；
2. 生成工作状态、收纳状态和中间姿态；
3. 检查所有附件是否进入模型；
4. 计算运动轨迹、碰撞和折叠外包络；
5. 保存参数、代码版本和结果图。

### 阶段 B：驱动与受力

1. 估算重力矩、驱动力和支撑反力；
2. 比较手动、助力与电动需求；
3. 检查止挡与锁紧是否独立承力；
4. 对最危险姿态做参数敏感性分析。

### 阶段 C：恢复与打印对照

1. 把展开后的几何基准与原机比较；
2. 明确哪些误差能由调平补偿，哪些属于机架变形；
3. 用同一测试文件进行恢复打印；
4. 将实测结果回写模型，不把第一次虚拟输出当成最终结论。

## 五、参数扫描设计

- 只有 2–3 个离散机构选项时，逐一计算全部组合；
- 有多个连续不确定参数时，使用覆盖参数空间的采样，而不是只算一个“看起来正确”的点；
- 同一模型的重复运行不是独立实测证据，只能检查数值稳定性；
- 敏感性分析必须指出哪个参数改变导致碰撞、力矩或变形越界；
- 未确定的合格阈值先记录为“待基线测量后冻结”，不得事后为通过而修改。

## 六、工具与已有参考

- **MotionGen**：Mario 项目用于连杆可视化，可作为四连杆早期辅助工具；[项目说明](https://mariosultan.com/anti-portfolio/folding-3d-printer-mod/)。
- **CAD／FreeCAD／Fusion／Onshape**：用于同尺度装配、姿态与碰撞检查，保留源文件版本。
- **Python＋Shapely**：用于二维扫掠、旋转与布尔碰撞检查；当前脚本只做方法自检。
- **Klipper 测试框架**：若进入自定义运动学，需增加专门运动测试；[官方代码说明](https://www.klipper3d.org/Code_Overview.html)。
- **FullControl**：用于明确生成和预览路径，不代替机构验证；[项目](https://github.com/FullControlXYZ/fullcontrol)。

## 七、当前可执行脚本

`scripts/virtual_fold_checks.py` 提供：

- 铰链旋转扫掠与障碍相交面积计算；
- 理想剪刀高度与几何导数；
- 外部翻转的静态重力矩估算；
- 方法自检，验证旋转、碰撞检测和公式能运行。

脚本自检只证明计算方法按预期工作，**不证明任何当前折叠方案可行**。实机参数填入 `data/virtual_validation_parameters.csv` 后才能形成方案级结果。

## 八、结果文件要求

每个方案至少保存：

- 输入参数表及来源；
- 工作与收纳状态图；
- 关键中间姿态与碰撞图；
- 最小间隙、最大力矩和其他相关结果；
- 失败参数组合；
- 结论：继续／修改／停止，以及对应的实测任务。
