# 关键结论纠偏记录 (RESULT_CORRECTIONS)

1. **F09 刚度与收纳比纠偏（V3 -> V3.1 Final -> V3.2.1）**：
   - V3 误将 10 N 载荷施加于横梁中心（`0.030 mm`）；V3.1 补齐 215 mm X 向悬臂末端载荷后 Y 向挠度为 `0.1252 mm`。
   - V3.2 原参数 `lift=85.0 mm` 含 215 mm 折叠 X 臂与附件后收纳比为 `0.802 > 0.800`（整体筛选 `FAIL`）；V3.2.1 在保持 `0.800` 门槛不变的前提下，将 `lift` 几何微调至 `82.0 mm` 并重新建模验证，使 `F09_L82` 收纳比降至 `0.786 <= 0.800`（整体筛选 `PASS`）。
2. **连续碰撞认证上界纠偏（V3.2 -> V3.2.1）**：
   - V3.2 `_motion_upper_bound()` 仅用起点/中点/终点估算位移，在 `x(t)=50*sin(2πt)` 反例中于 `t=0.25` 真实穿透 `2.0 mm` 时误判 `PASS`。
   - V3.2.1 改为显式解析运动上界契约 `BoundedTrajectory`，缺少可信上界的任意 `Callable` 强制返回 `UNRESOLVED`。
3. **微米级净距工程边界说明**：
   - `F09_L82` (`0.023 mm`)、`F07` (`0.021 mm`)、`SCZ` (`0.010 mm`) 的最小认证净距仅证明简化 OBB 几何模型无碰撞，**不构成覆盖真实加工与装配公差的工程安全余量**。
