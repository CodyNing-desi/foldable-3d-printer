# 当前折叠方向：补充案例与证据缺口

日期：2026-11-12

## 一、按当前八条方向组织证据

| 当前方向 | 可回查案例 | 可以借用的机构做法 | 证据缺口 |
|---|---|---|---|
| 单立柱根部翻折 F01／F07／F08 | Positron、FoldaRap、ProperPrinting Ender 3、Mario 改型、CN105034368B | 根部转轴、硬止挡、定位面、锁扣／肘节夹、助力与阻尼 | 根部弯矩、反复展开偏移与锁点寿命仍需本机实测 |
| 横臂收拢 F02 | 当前主要是本组概念；M01 提供多关节组合思路 | 横臂与 Z 滑块之间的转动接口、定位销与预紧锁紧 | 本轮未找到足够直接的成熟横臂下折打印机案例，需重点验证新增质量、线缆和末端挠度 |
| 双柱龙门翻折 F03／F09 | Odin-5、FoldaRap、ProperPrinting Ender 3、TeeBotMax | 整框翻折、左右共轴／联动、双端卡止、底部附件迁移 | 双侧角差、整框重量与同步轴扭转变形不能由图片证明 |
| 复合避让折叠 F04／F10 | ProperPrinting 四连杆、CN110815813B、Arthur Tollet 杠杆构想 | 先平移／抬离再翻倒；滑块、连杆与阻尼共同组织轨迹 | 自由度、死点、槽轨接触力和实际避让空间需要参数化模型 |
| 伸缩立柱 F05／F12 | Nomad 仅提供伸缩导轨参考；其他升降柱产品不能直接证明打印精度 | 重叠段、分级锁定、导向垫块与级间消隙 | 本轮未找到直接成熟的多级 Z 立柱打印案例；打印 Z 连续行程和抗扭是核心缺口 |
| 外部托架翻转 F06／F14 | 当前主要是本组概念；普通打印机的快拆与支撑经验仅作旁证 | 外部托架、水平承力锁杆、吊索助力与独立收纳锁 | 柜深、重心、安装承载与失电保持缺直接打印机证据 |
| 箱体联动工作站 F11 | Case-Rap、Tobeca、TeeBot／TeeBot_Suitcase、Nomad、Positron | 框架兼作箱体、附件收纳、开箱后展开、全部部件固定 | 箱体重量、联动轨迹、开合角度和实际容纳关系必须做足尺寸模型 |
| 抽屉式 Y 模组 F13 | Nomad 伸缩导轨、JobOx 换板、Positron 可拆床板 | 伸缩／抽拉、磁吸复位、定位面与多点压紧 | 未找到直接证明“整个 Y 导轨＋热床＋驱动作为抽屉模组”的成熟案例；停靠重复性与线缆磨损待测 |

## 二、最有参考价值的新增案例

### ProperPrinting：Ender 3 Pro 四连杆折叠实改

[Hackaday 报道](https://hackaday.com/2019/12/26/folding-an-off-the-shelf-3d-printer/)与[作者项目页](https://properprinting.pro/product/foldable-ender-3-pro/)显示：

- 为折叠顶部框架，先迁移显示器与电源；
- 四连杆使竖直框架在折下时同时向机器前方平移；
- 关节使用碳纤增强尼龙打印件、螺栓轴、螺纹杆和滑动安装点调节；
- 两侧支架帮助机器在立起和折下位置卡止；
- 作者明确提醒长期使用后的间隙仍需观察。

**对本组的价值**：它是 F04／F10“先避让、再折下”的真实参考，也说明折叠不只是加一对铰链，还牵涉显示器、电源、附件和重复卡止。

### Mario Sultan：硬止挡＋肘节夹与 MotionGen

[Mario 的折叠 Ender 3 项目](https://mariosultan.com/anti-portfolio/folding-3d-printer-mod/)在 ProperPrinting 基础上尝试：

- 用肘节夹提高锁紧的一致性；
- 用 90°支架作为硬止挡与定位件；
- 通过多孔样件和 T 槽滑动件试验不同连杆安装点；
- 使用 MotionGen 可视化连杆运动。

该项目页明确标记 **INCOMPLETE PROJECT**，不能作为完成机器的证据；但它提供了很直接的“定位＋锁紧＋虚拟连杆验证”路径。

### TeeBotMax／TeeBot：开源折叠与箱体资料

- [TeeBotMax RepRap 页](https://reprap.org/wiki/TeeBotMax)将其标为 working，并提供构建资料链接；历史报道给出工作／折叠尺寸和 7 kg 重量，但这些不是本组实测。
- [TeeBotMax GitHub](https://github.com/EmmanuelAdetutu/TeeBotMax)与[TeeBot_Suitcase](https://github.com/EmmanuelAdetutu/TeeBot_Suitcase)已保存到 `external/`。
- TeeBotMax 的 GitHub 元数据为 GPL-3.0，而 RepRap 页写 CC-BY-SA-3.0；本档案明确保留这一许可标识差异，公开复用时需进一步核查。

### CN113787715B：多段折叠框架与导轨保护

[专利文字](https://www.xjishu.com/zhuanli/35/202111165018.html)描述了上／下平台、三组折叠部、多个铰接与固定件；折叠后部分构件在竖直滑轨外侧形成保护。

**价值**：提供“折叠后同时保护导轨和喷头”的思路。  
**代价**：解锁与转动步骤多、零件多；专利不证明实际可靠性，也不证明适合本组快速展开目标。

### 派设际／Anycubic 概念：只能作为形态参考

[设计方页面](http://www.design-pai.com/product/91.html)展示五个旋转轴、75 mm 折叠高度与 460 mm 打印高度等宣称。当前没有把这些数字作为实机测量，也没有把多轴外形当成连续五轴打印证据。

## 三、对虚拟验证的直接影响

1. 有实改案例的路线也要重新建模，不能复制图片中的几何。
2. 根部翻折先算运动包络、根部力矩、锁紧与参考点偏移。
3. 四连杆／槽轨路线先做参数化运动，验证可达性、死点和碰撞，而不是先做外观。
4. 伸缩、外部托架与抽屉路线缺直接案例，更需要通过虚拟模型排除明显不成立的几何关系。
5. 箱体路线必须包含电源、料盘、打印板、工具和线缆，不能只计算机身。
