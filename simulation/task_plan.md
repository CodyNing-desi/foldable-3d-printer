# Task Plan: 可折叠 3D 打印机全方案虚拟仿真与优化筛选

## Goal
对仓库中的 F01–F14、剪刀式 Z 轴及发现的其他候选机构运行可复现的统一初筛、入围深化仿真和多目标优化，提交真实数据、CAD、动画、图表、报告及 Git 提交，推荐 2–3 套实测方案。

- [x] Phase 1: 克隆并审计仓库、资料、CAD、历史算法和依赖
- [x] Phase 2: 建立全部机构的统一参数、假设、单位和评价契约
- [x] Phase 3: 实现并运行全机构运动可达性、碰撞、包络和工作空间初筛
- [x] Phase 4: 对入围方案运行力矩、载荷、变形、锁紧刚度和重复定位误差深化仿真
- [x] Phase 5: 运行参数扫描、敏感性分析和 NSGA-II，多目标筛选并保留失败案例
- [x] Phase 6: 生成并检查 CAD/STEP、折叠动画、对比图和最终中文报告
- [x] Phase 7: 全流程复现验证、清理、Git 提交与交付

- [x] Phase 9: 全实验过程复盘、README 更新与 GitHub 同步

## Key Questions
1. 仓库实际包含哪些候选机构、设计变量、可信尺寸和可复用 CAD？
2. 哪些结果来自真实三维几何、解析/数值模型、多体动力学或有限元，各自证据等级是什么？
3. 哪些方案因硬约束失败而淘汰，哪些进入 Pareto 前沿，推荐对假设和权重是否稳健？

## Decisions Made
- 采用统一初筛后深化入围方案的两阶段计算，避免把算力耗在明显不可行机构上。
- 所有缺失尺寸、材料、载荷、成本均显式标注为假设并做区间敏感性分析。
- 不修改 `external/` 上游原件；所有新增模型和输出放在仓库内独立目录。
- 用户已明确授权自主连续执行和 Git 提交，不设置额外设计确认中断。
