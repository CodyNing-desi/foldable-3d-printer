# 可折叠 3D 打印机｜V3.1 第三轮补充验证与终审报告

> **证据边界声明**：本报告基于 `simulation_v3_1/` 修复后的 3D OBB 15 轴 SAT + 保守自适应扫掠碰撞（`step_bound = 1.0 mm`）、统一 215 mm 悬臂载荷 3D 6-DOF 空间梁架有限元及运动学/驱动力敏感性分析。所有材料模量（`69,000 MPa`）、连接柔度折减（底座 `0.55`、角板 `0.70`）、摩擦系数与制造间隙均为工程假设，**不代表已通过实机打印精度认证**。

## 1. 对五个核心问题的明确回答

1. **F09 加入真实工具头悬臂后，刚度是否仍明显优于 F07？**
   **是的，依然明显更优（约 6.77 倍）。** 补齐 215 mm X 向悬臂并在末端施加 10 N 侧载后，F09 末端 Y 向挠度由 V3 的误算值 `0.0304 mm` 修正为 **`0.1207 mm`**（理想刚性锁紧为 `0.1004 mm`），X 向 `0.1023 mm`、Z 向 `0.2085 mm`；而同口径下 F07 为 Y 向 **`0.8166 mm`**、X 向 `0.2012 mm`、Z 向 `0.3307 mm`。双柱闭环龙门消除了单立柱底座扭转柔度。
2. **F07 是否存在真正满足全部几何约束的可制造折叠参数？**
   **存在，但可行参数窗口较窄。** 限定 `shift_x >= 0` 以避让抬升丝杆后，`lift_mm = 75 mm, shift_x_mm = 0 mm` 在 201 姿态保守自适应扫掠下实现 **`0.0000 mm` 穿透**，且含 `200×200×70 mm` 附件后的 3D 收纳比为 **`0.783 <= 0.800`**；当 `lift_mm >= 80 mm` 时收纳比升至 `0.815 > 0.800`。
3. **F09、F07、SCZ、F08 的完整运动路径是否真正无干涉？**
   在 `step_bound = 1.0 mm` 保守自适应扫掠包络下，**F09 (`lift=85`)**、**SCZ (`arm=154, h_fold=45`)**、**F07 (`lift=75, shift_x=0`)** 与 **F08 (`lift=25/30, shift_x=-75`)** 均实现 **`0.0000 mm` 穿透**（其中 F09 与 SCZ 在运动末态含附件最小安全间隙为 **`2.00 mm`**，F07/F08 运动起步前 `t<=0.05` 存在 `z=20.0 mm` 底座基准齐平接触）。
4. **SCZ 的驱动力和回差风险是否适合进入线下台架实验？**
   **适合作为“有条件入围（Conditional Go）”进入最小化剪刀台架实验，但不适合直接做整机。** 计算表明 `H=125 mm` 时 NEMA17（`0.55 N·m`）安全系数充足（T8 丝杆 `10.79`、SFU1204 `8.39`），但 V3 的 `0.385 mm` 回差与 `0.15 mm` 门槛存在明确冲突——仅靠假设“预紧滚珠丝杆 + 铰孔销轴（间隙 `<= 0.015 mm`）”才可将理论回差压至 `0.096 mm`，必须通过台架实测验证。
5. **哪些候选正式进入实体测试，哪些有条件入围？**
   受限于关键关节摩擦、间隙与同步偏差尚未实测，**本轮无任何方案获得无条件 `Go`**；推荐 **F09、F07、SCZ** 获 **`Conditional Go`** 进入首批最小化台架/试片验证，**F08** 保留为 **`Conditional Go (Backup)`**，**F12** 维持 **`No-Go`（暂停）**。

## 3. F12 有限范围复核与仍然未知的工程风险

- **F12 复核结论**：侧置电机 + 预紧导轨版 F12 在 V3.1 扫掠与 3D 刚度上自洽（`0.0612 mm` 弹性挠度 + `0.229 mm` 间隙游隙，收纳比 `0.735`），但三级精密套筒加工与多级导轨预紧装配在六周课程内交付风险极高，维持 **No-Go（暂停）**。
- **仍然未知的风险**：铰链实际摩擦系数与磨损衰减、200 次锁紧后的预紧力保持率、剪刀销轴扩孔后的实际游隙、热床热辐射对导轨/塑料件的漂移影响。
