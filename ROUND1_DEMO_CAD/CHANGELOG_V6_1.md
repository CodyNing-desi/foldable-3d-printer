# R1-V6 → R1-V6.1 变更对照表（装配拓扑修复）

日期：2026-11-17。触发：总装说明书编制过程中对"步骤能否真的装起来"的实操核查。

## 问题（装配拓扑缺陷，运动学验证无法发现）

V6 及之前的导向塔 TWR 为 **塔足 + 双导柱 + 顶盖** 单一打印件，顶盖桥接两导柱顶端
（z63..67 local，world z73..77）。滑座 CAR 的轴套为闭口圆孔（Ø5.3 通孔）：

- 闭口孔套入两端均被塔足/顶盖封闭的导柱，**拓扑上无解**——先装塔再套滑座不行，
  先套滑座再装塔也不行（塔本身即为一个件）；
- F09 的 SYNC 同步杆需从上往下套过内侧导柱（Ø5.4 过柱孔），同样被一体顶盖封死；
- 网格实证：TWR 单一水密实体，z=67 顶面水平截面积 290 mm²（完整顶盖；两根裸柱应仅 ~39 mm²）。
- 既有 L2 穿透扫描与 L2b 闭合检查均通过——它们验证运动与配合，**不验证装配顺序的可行性**。

## 修复（最小改动，外部包络不变）

| 项 | V6 | V6.1 |
|---|---|---|
| 顶盖 | 与塔一体 | **独立 CAP 件**：套入导柱顶（z63..67），每塔 2×PIN3-L14 横穿顶盖+导柱 z65 孔 + CLIP3 |
| TWR | 含顶盖 | 不含顶盖；新增顶盖销孔 Ø3.2@z65（z48 滑座锁孔不变） |
| 装配顺序 | 塔→滑座（不可行） | 塔→套滑座→（F09 先装 SYNC）→锁顶盖 |
| 销轴数量 | PIN3-L14：4/塔 | PIN3-L14：6/塔（塔足 4 + 顶盖 2）；CLIP3 同步 +2/塔 |
| 新增零件 | — | F07-CAP ×1 / F09-CAP ×2（PLA，平放打印） |
