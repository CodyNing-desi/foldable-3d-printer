# V3.2 模型边界与已知局限 (MODEL_LIMITATIONS)

1. **OBB 几何近似**：所有零件及线缆/料盘等附件均以有向包围盒（OBB）建模，未包含倒角、螺钉凸台及柔性线缆弯曲动态。
2. **线弹性梁单元 FEA**：`fea3d.py` 采用 3D Euler-Bernoulli 空间梁单元与集中弹性关节系数（`base_factor=0.55`, `corner_factor=0.70`），未模拟接触非线性、螺栓预紧松弛及热变形。
3. **静止基准面豁免**：`F09/F07/F08` 在 `t <= 0.20` 抬升启动前，立柱底面与底座顶面呈 `0.0 mm` 贴合接触，该基准面静置阶段仅检查零穿透，不作为运动间隙报警。
4. **物理样机未制造**：本轮及历史所有版本均未执行实际采购、加工或台架实测，最终锁紧刚度与装配公差需在后续实体台架阶段验证。
